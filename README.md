# My Daily Python Ritual

### 1. Start Working
change directory cd python_learning

Activate the virtual environment (look for `(my_env)` in the terminal):
`source my_env/bin/activate`

---

### 2. Run Code
Run your Python program:
`python3 hello.py`

*(Replace `hello.py` with whatever file name you want to run)*

---

### 3. Stop Working for the Day
Deactivate the virtual environment:
`deactivate`

Clear the terminal screen:
`clear`

Close the terminal:
`exit`
